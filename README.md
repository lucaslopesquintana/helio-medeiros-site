# Hélio Medeiros — Site Oficial & Portfólio Acadêmico

Site profissional e portfólio acadêmico do jurista **Hélio Medeiros**, Procurador Municipal de Porto Alegre (RS), Doutorando e Mestre em Teoria Geral da Jurisdição e do Processo pela Pontifícia Universidade Católica do Rio Grande do Sul (PUCRS) e Vice-Diretor da Fundação Escola Superior de Direito Municipal (ESDM).

---

## 🏛️ Sobre o Projeto

Plataforma institucional de alta performance desenvolvida com estética editorial de luxo (Dark Navy `#050B14` e Champagne Gold `#E5C384`), projetada para destacar a confluência entre a efetividade processual e a segurança jurídica.

### Principais Seções e Funcionalidades:
- **Hero Institucional**: Confluência dogmática, botões de ação e retrato oficial com enquadramento refinado.
- **Conheça Hélio Medeiros**: Apresentação biográfica completa, atuação contenciosa na PGM de POA e histórico na PUCRS / IBDP.
- **O Método (Artigo 370 do CPC)**: Seis pilares da dogmática probatória e métricas de impacto acadêmico/profissional.
- **A Obra (2ª Edição — Editora Thoth)**: Vitrine imersiva com mockup 3D e visão plana da capa do livro *"Poderes Instrutórios do Juiz no Processo Civil"*, com prefácio do Prof. Dr. William Santos Ferreira e apresentação do Prof. Dr. Luís Alberto Reichelt.
- **Ensaios & Pareceres Dogmáticos**: Catálogo de artigos jurídicos com busca e filtro por temas, modal de leitura imersiva e gerador automático de citação ABNT (NBR 6023).
- **Área Restrita do Autor**: Painel administrativo para acompanhamento, edição e publicação de novos artigos com persistência local.
- **Reveal on Scroll**: Transições e animações fluidas via *Intersection Observer API* nativa.

## 🚀 Instalação e Execução Local

Clone o repositório e instale as dependências:

```bash
# Instalar dependências
npm install

# Rodar servidor local de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
